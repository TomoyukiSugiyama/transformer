# Phase 4: 日本語コーパスへの拡張 (青空文庫 / 夏目漱石)

英語 (Tiny Shakespeare) の Phase 3 で nanoGPT 級品質を達成したのち、 **同一モデル構造のまま
日本語コーパスでどこまで行けるか**を検証した。 トークナイザは BPE では UTF-8 マルチバイト境界
で文字化けが発生したため **char-level 一択**となる ( 1 char ≒ 1 token、 vocab はコーパス出現
文字から自動構築)。

## Phase 4a: 「こころ」 単体 (`Config::aozora_kokoro`)

| 項目 | 値 |
|------|----|
| corpus | 夏目漱石「こころ」 (162k char) |
| val_tokens | 16,247 (10% tail split) |
| その他構造 | Phase 3 と同一 (d_model=384, n_heads=6, n_layers=6, dropout=0.2, wd=0.1) |
| end_step / save_every | 1000 / 100 |

### val_loss 推移

| step | train ema | val_loss | val_ppl |
|------|-----------|----------|---------|
| 100 | 3.537 | 3.408 | 30.20 |
| **200** | **2.642** | **2.898** | **18.15** ← ピーク |
| 300 | 1.900 | 3.017 | 20.43 |
| 400 | 1.129 | 3.476 | 32.34 |
| 500 | 0.579 | 4.063 | 58.17 |
| 1000 | 0.142 | 5.140 | 170.67 |

**step 200 で最良、 以降は急峻に過学習**。 162k char に対し 10.7M params はモデル容量過大で、
train loss は 0.14 まで落ちるのに対し val_ppl は 9 倍以上に悪化する典型例。

### Phase 4a vs 4b 比較

| 指標 | Phase 4a (Kokoro 単体) | Phase 4b (Soseki 7 作品) | 倍率 |
|------|----------------------|-----------------------|-----|
| corpus_tokens | 146k | 1.086M | **7.4×** |
| best val_ppl | 18.15 | 18.98 | ほぼ同等 |
| best step | 200 | 700 | **3.5×** 遅延 |
| train ema @ best | 2.64 | 2.41 | (わずかに低い) |

**観察**:
- コーパス 7.4 倍 → 過学習開始の step も 3.5 倍遅延し、 想定通り過学習耐性が向上
- ただし best val_ppl はほぼ同等 (18.15 → 18.98)。 vocab が増えた (Kokoro より多様な漢字)
  ことと、 d_model=384 / n_layers=6 のモデル容量が **データ側ではなく容量側で律速**して
  いることを示唆 (Chinchilla 則的に言えば、 10.7M params に対し 1M tokens は学習側の余地あり)
- 次のステップとして、 **モデル拡大** (d_model=512〜) または **アーキテクチャ刷新** (RMSNorm / SwiGLU /
  RoPE) で val_ppl を更に押し下げる余地がある

## 推論サンプル (Phase 4b best.bin = step 700)

`top_k=5, temperature=1.0, repetition_penalty=1.2, max_new_token=100` で生成:

```
[prompt: 私は]
私はこの問題として、そうしてそれがために私を思い留めた事を考えたら、一時間ばかり前、先刻私の頭を
抑えています。 我々がＫと私はどんな話をした後です。しばらく彼の口から受ける気分でもあったのです。

[prompt: 先生は]
先生は「あなたに会うんですか」と聞き直している。
私がまたこれだけで、その時の奥さんの言葉を使うのが厭だろうと思っているので、私の頭はそこにも判断
しておくれるよりも、その意味も解らないと思っているのです。

[prompt: 東京の]
東京の方です。
それを奥さんがまたお嬢さんに対してはいなかったのだと思うので、私はどうもこういう気分にいるだろうと
考え込んでした。私はその時彼の顔を見る事になるのだろうと答えたのです。

[prompt: 吾輩は]
吾輩はその後にから、一番先生がまた一枚の箱を持って、私はすこぶる曖昧でしょう。
私は何というものと心得なかった。私にはＫといえども、彼らの眼に映じた事がありません。
```

**定性評価**:
- 漱石作品の登場人物 (**Ｋ / 先生 / 奥さん / お嬢さん / 三沢**) が正しく生成される
- 鉤括弧 「」 が概ね閉じる、 句読点バランスが自然
- 漢字仮名比率が原典に近い (漢字過多や仮名過多に偏らない)
- **論理整合性は依然崩壊** ( 「奥さんがまたお嬢さんに対してはいなかった」 等の助詞乱れ)
- 「吾輩はこの家の猫である」 等は **ほぼ原文を記憶**している (overfitting の片鱗)

英語 [Phase 3](phase3.md) のシェイクスピア生成と比較すると、 **同じ val_loss = 2.94 帯に到達しても日本語の方が
論理崩壊が目立つ**。 これは:
- 1 文字の情報量が日本語 (漢字) > 英語 (アルファベット) で、 char-level では実質 sequence が短い
- 日本語特有の助詞・係り受けが char-level で局所的に学習しにくい
